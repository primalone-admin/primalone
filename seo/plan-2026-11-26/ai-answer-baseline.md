# AI-answer baseline (roadmap C1)

**Status:** ready to run (not run yet). It needs a person with access to each engine.
**Sheet:** [ai-baseline-log.csv](ai-baseline-log.csv): 29 questions × 4 engines = 116 rows.
**When:** run once **before** the SEO build goes live (the "before" picture), then again 6–8 weeks after, and after each major content change. Always use the same questions so runs are comparable.

## How to run it

1. Use each engine the way a customer would: **logged out** if possible, location India, web search on where the engine offers it. Write the mode in the sheet.
2. Paste each question **exactly** as written. Don't add "PrimalOne" to questions that don't already contain it.
3. For each answer, fill in:
   - whether PrimalOne is mentioned
   - whether it is cited with a link, and which link
   - whether the facts about PrimalOne are right (check them against the product pages)
   - which competitors are named
   - which sources the engine cited
4. Take a screenshot of each answer and record its filename. AI answers change from run to run, so the screenshot is your evidence.
5. Ask each question once per run. Don't regenerate the answer until you get a better one.

## How to read the results

- Count, **per engine** (not one combined score):
  - mention rate (mentioned ÷ questions)
  - citation rate
  - wrong-fact count
- Treat **wrong facts** as the most urgent finding. Wrong prices, ingredients, or "subscription" claims are fixed at the source: the site, social bios, and press listings (roadmap C4).
- The **"sources cited"** column shows which sites the engines trust for your category. Those are the outreach targets for roadmap B4.
- Before/after differences are **observations, not proof** that a change caused them. Engines change on their own.
